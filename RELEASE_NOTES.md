## Alpha hack lite 3.0.0 beta 1
GD 2.2091 / Geode 6.0.0-alpha.1, Windows x64 + Android ARM64.

Use **Geode → Installed → Alpha hack lite → Settings**.

Only **Unlock Icons** and **Practice Music Sync** remain. No CBF button or CBF integration.

Removed custom menus, floating buttons, HUD, cheat indicator, speedhack, native TPS patches, FPS/VSync/Smooth Fix overrides, song replacement and main-level unlocks. Removed the corresponding source modules rather than hiding their UI.

Retains mod ID `dim5l.practice_sync` to replace the full build. **Restart the game after installing.** Old settings for removed features are ignored. Lite does not change timing or input handling.

CI builds and verifies both native binaries. In-game execution has not been device-tested.
